# # 🛒 E-commerce Sales Analysis Using Microsoft Excel

## 📌 Project Overview

This project focuses on analyzing an E-commerce sales dataset using **Microsoft Excel**. The objective is to clean and organize raw data, apply Excel formulas, combine tables, perform statistical analysis, and build an interactive dashboard to generate meaningful business insights.

This project demonstrates practical data analytics skills, including data cleaning, data transformation, data analysis, data visualization, and reporting.

## 🎯 Project Objectives

- Import and organize the E-commerce dataset using Excel tables.
- Clean data by handling missing values, duplicates, inconsistent entries, and formatting errors.
- Remove irrelevant columns, if any.
- Apply Excel formulas for calculations, summaries, and logical operations.
- Combine tables using XLOOKUP or VLOOKUP.
- Create Pivot Tables and PivotCharts for sales analysis.
- Calculate descriptive statistics such as mean, median, mode, and standard deviation.
- Build an interactive dashboard to present key performance indicators (KPIs) and business insights.

## 📂 Dataset Information

**Dataset:** E-commerce Store Dataset

**Source:** [GitHub – E-commerce Sales Dataset](https://github.com/GeethaGunasekaran1/Dataset_rep/raw/refs/heads/main/Ecommerce_Sales_Dataset_updated.xlsx)

## 🔄 Project Workflow

### 1. Data Import and Organization
- Imported the dataset into Excel.
- Organized the data into structured Excel tables.
- Reviewed column names, data types, and dataset structure.

### 2. Data Cleaning and Validation
- Identified and removed duplicate records where appropriate.
- Checked for missing values and handled them using suitable methods.
- Corrected inconsistent text entries and spelling errors.
- Fixed date, number, and other formatting issues.
- Validated data to improve accuracy and consistency.
- Removed irrelevant columns, if present.

### 3. Data Transformation and Formulas
Applied suitable Excel functions based on the available columns:

- `SUM()` – Calculate totals
- `AVERAGE()` – Calculate averages
- `COUNT()` and `COUNTA()` – Count records
- `IF()` – Apply logical conditions
- `IFERROR()` – Handle formula errors
- `XLOOKUP()` / `VLOOKUP()` – Retrieve and combine related information
- `TEXT()` and text functions – Clean or transform text values
- `MIN()` and `MAX()` – Identify minimum and maximum values

### 4. Descriptive Statistical Analysis
Calculated statistical measures using Excel formulas or the Analysis ToolPak:

- Mean
- Median
- Mode
- Standard deviation
- Minimum and maximum values
- Count of records

These measures help understand the distribution and variation of the available data.

### 5. Pivot Table Analysis
Created Pivot Tables to summarize the dataset and explore business performance across available categories, products, and other relevant dimensions.

### 6. Data Visualization
Created at least three chart types to communicate findings clearly:

- Bar or Column Chart
- Pie or Doughnut Chart
- Line Chart

PivotCharts were also used where appropriate to visualize summarized data.

### 7. Interactive Dashboard
Developed an Excel dashboard to present key metrics and visual summaries in one place. Where applicable, interactive filters such as Slicers and Timeline controls were used to explore the data dynamically.
